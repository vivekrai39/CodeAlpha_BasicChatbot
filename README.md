# CodeAlpha_BasicChatbot
A simple rule-based chatbot built using Python
## About the Project

Basic Chatbot is a simple rule-based chatbot developed using Python. It responds to user messages with predefined replies.

## Features

- Responds to `hello` with `Hi!`
- Responds to `how are you` with `I'm fine, thanks!`
- Responds to `bye` with `Goodbye!`
- Handles unknown messages with a default response.
- Continues chatting until the user types `bye`.

## Technologies Used

- Python
- Functions
- if-elif-else statements
- User input and output
- While loop

## How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run this command in the terminal:
   `python BasicChatbot.py`
5. Type a message such as `hello`, `how are you`, or `bye`.
